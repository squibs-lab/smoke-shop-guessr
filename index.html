Smoke Shop Guessr

The rounds come from Google Street View, so the game needs a Google Maps API key with the Maps Embed API turned on (free), and optionally the Maps JavaScript API for Street View without street names.

The key is saved in this browser only. Before the site goes online, paste the key into GOOGLE_KEY at the top of the script.
